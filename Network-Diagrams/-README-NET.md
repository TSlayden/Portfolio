These diagrams provide physical documentation of the facility's network infrastructure, mapping out key routing hubs, building-wide wireless coverage, and a high-speed production data line. They streamline Layer-1 troubleshooting and aid in capacity planning for future projects.

All diagrams were designed in Draw.io.

-Front Office Phone RM
This room operates as a secondary networking hub branching off from the main server room. The location houses core switches and integration points for analog phone lines, storm alarms, and the facility PA system. A second network hub (H-ME-Office) branches back to this location; specific topologies are detailed in a separate diagram.

-H-ME-Office
The Manufacturing Engineering Office houses number of network appliances and video conferencing equipment. The network infrastructure connects back to another hub (Front Office Phone RM) with connections to that hub detailed in this document.

-Trace Networking Physical
One production line runs Tier-1 parts for a customer and requires a low latency data collection system for robust part traceability. This diagram documents the 10GbE network and the connected data server. It serves as a vital tool for troubleshooting connectivity issues and outlining IT's maintenance responsibilities for stakeholders.

-Wifi Layout
This blueprint maps the physical placement of access points throughout the facility alongside their source network switches. It serves as an essential tool for visualizing Wi-Fi coverage and planning spectrum allocation to mitigate cross-device interference.
