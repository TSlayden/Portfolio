This is a collection of networking diagrams to highlight vital Layer 1 connections between critical production devices.

-Front Office Phone RM
This room is a networking hub branched off from our server room. It contains a handful of switches and other integration points with our phone lines, storm alarms, and PA system. A second hub network, M-ME-Office, branches back to this room. The specifics are detailed in a separate diagram.

-H-ME-Office
The Manufacturing Engineering Office contains a number of network appliances, as well as a set of Video conferencing equipment. The network branches back to the Front Office Phone RM and the relevant connections are detailed here

-Trace Networking Physical
One production line runs Tier-1 parts for a customer and requires a low latency data collection system for robust part traceability. This diagram documents the 10GbE network and the connected data server. It serves as a vital tool for troubleshooting connectivity issues and outlining IT's maintenance responsibilities for stakeholders.

-Wifi Layout
This blueprint maps the placement of access points throughout the building alongside their source network switch. It serves as an essential tool for visualizing hotspot coverage and planning spectrum spread to mitigate cross-device interference.
